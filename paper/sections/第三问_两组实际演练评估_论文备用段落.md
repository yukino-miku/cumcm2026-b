# 第三问两组实际演练评估：论文备用段落

> 本段依据用户指定的两组六次演练，区别于此前的本地构造实验与未来正式测试。完整数据和来源见[演练评估报告](../../docs/第三问/两组演练评估_s1_s2.md)。

在相同程序版本和组内一致配置下，对七站搜索与自适应定位方案、固定双覆盖扫描后精定位方案分别分析6次实际演练。通过模拟器导出的结果JSON核对目标总数，以对应jlog包的SHA256确认文件关联，再以相同队号与1～2毫秒的退出时间差关联本地HTTP记录。两组成功清除数分别为78和72，与对应结果文件中的目标总数逐局一致，12局均正常退出。日志费用按2605个不同动作独立重算通过。

| 指标 | 方案一 | 方案二 |
|---|---:|---:|
| 全清演练次数 | 6/6 | 6/6 |
| 平均每局目标数 | 13 | 12 |
| 平均总虚拟时间（秒） | 4595.698 | 4914.840 |
| 各局每目标时间均值（秒） | 364.989 | 414.429 |
| 平均路程（米） | 18727.657 | 16154.201 |
| 平均检测次数 | 131.833 | 273.000 |
| 平均专门追加测向次数 | 16.667 | 1.000 |
| 失败清除总次数 | 2 | 0 |

结果显示，方案一平均总时间较方案二低6.49%，按各局T/N等权平均则低11.93%。方案二平均节省约514.691秒移动费用，但额外增加705.833秒检测费用和134秒切换费用，因而本组完整任务平均费用更高。

两组案例码不重合，未确认同场景配对，且目标数分布不同。限制在两组共有的10、12、14个目标层，并给予各层相同权重后，平均每目标费用为390.956和414.429秒，方案一仍低5.66%。不过，方案一每层仅1局、方案二每层2局，目标位置及接收半径等差异未被控制，因此该结果仅支持当前优先采用方案一，不构成总体显著优越性或更高成功率的证明。

两次失败清除均属于方案一有限方格覆盖过程，费用已计入，最终全部目标均被清除；两组均无通信异常或重试。本页结果为实际演练，不是正式测试成绩。未解密jlog/psum正文，也未将本地构造实验与实际演练混合统计。
