# 任务清单

## 初始化

- [x] 检查来源目录、Git 与 GitHub 登录状态。
- [x] 建立项目结构、协作约定和同步工具。
- [x] 创建私有 GitHub 仓库并推送初始提交。
- [x] 原样归档全部题目和附件，生成并验证 SHA256 清单。
- [x] 确认工作区干净、本地与远端提交一致。

## 用户开始正式建模后

- [ ] 阅读赛题、整理问题要求及最终交付格式。
- [ ] 检查附件结构、字段、单位、缺失值和数据约束。
- [ ] 明确假设、符号、评价指标与验证方式。
- [ ] 制定建模与求解方案，逐步实现和验证。
- [ ] 整理结果、图表、稳健性分析及论文。
- [ ] 复现最终结果，核对提交材料。
