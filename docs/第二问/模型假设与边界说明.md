# 第二问模型假设与边界说明

本文集中说明哪些条件来自正式题面，哪些属于建模选择，哪些只是数值实现设置。详细推导见[思路与数学推导](思路与数学推导.md)。

## 1. 正式参数及其用途

| 项目 | 正式值或条件 | 在模型中的用途 |
|---|---|---|
| 目标区域 | 以 $O=(0,0)$ 为中心，半径 $1800$ 米 | 限制未知目标位置，不自动限制机器狗站点位置 |
| 全向有效接收半径 | $1000$～$1500$ 米，具体值未知 | 首次成功接收用 $1500$ 米作上界；保证二次接收用 $1000$ 米作下界 |
| 示向误差 | 全部落在 $[-1^\circ,1^\circ]$ | 确定性角域约束，不能自行改成高斯误差 |
| 近距规则 | 距离不超过 $5$ 米时不能取得普通示向度 | 第二站必须对所有可能目标避开近距阈值 |
| 示向度 | 从 $x$ 轴正向逆时针计角 | 与第一问一致，计算中处理 $0^\circ/360^\circ$ 跨越 |
| 研究对象 | 首次已检测到的某个全向干扰源 | 不在第二问中混入多源关联和定向源可见扇区问题 |

依据为[正式 B 题 PDF](../../materials/original/problem/B题.pdf)及归档附件。敏感性实验中调整误差半宽、半径下界等参数，只是理论拓展或算法验证，正式输入仍使用上表值。

## 2. 建模选择与保守性

| 选择 | 原因 | 解释边界 |
|---|---|---|
| 沿用角域定位直径 | 保持与第一问的评价连续性 | 不以面积、方差或估计点误差无理由替换 |
| 将首次物理可行域记为角楔与两个圆的交 | 单次方向信息无界，需要结合已有物理先验 | 该集合具有圆弧，不能直接套第一问多边形顶点作为全部物理边界 |
| 首次暂不删除 $5$ 米内区域 | 保留紧凸结构，便于连续距离与方向分析 | 只扩大不确定集合，属于保守处理；不代表近距存在示向度 |
| 第二站排除可能近距无示向度场景 | 两次角域交会必须确实得到两次方向信息 | 可靠接收与可靠测向应分别输出状态 |
| 对所有允许目标和第二次误差取最坏值 | 题目未给概率分布 | 数值样本均值或分位数不是概率保证 |
| 只优化定位质量，保存移动距离 | 题目第二问关注候选区域，后续问题可再权衡路线 | 不提前把移动时间混入主目标 |
| 用正裕度避开距离临界值 | 主搜索取 $\rho=10^{-5}$ 米，以 $F\le1000-\rho$、$f\ge5+\rho$ 定义闭安全子域 | 裕度是数值工程设置，不是官方半径变化；浮点解析查询不是区间算术认证 |

统一半径 $1000$ 米给出保守充分条件。首次成功检测还意味着实际接收半径不小于 $\|G-S_1\|$；若充分使用这一条件，可放宽为

$$
\mathcal K_{\rm cond}=\bigcap_{G\in\Omega_1}
B\big(G,\max(1000,\|G-S_1\|)\big),\qquad
\mathcal K\subseteq\mathcal K_{\rm cond}.
$$

本轮保留用户建议的统一 $\mathcal K$，未优化这个扩展。因此 $\mathcal K$ 外的点应称为“未通过本文统一准则”，不能不加条件地断言它无法保证接收。代码的可靠性布尔字段、图表对照及最优区域均针对本轮统一模型，也不代表所有条件策略中的全局最优。

## 3. 四个核心集合不可混用

$$
P=W_1\cap W_2,
\qquad
\Omega_1=W_1\cap B(S_1,1500)\cap B(O,1800),
$$

$$
\mathcal K=\{S:\max_{G\in\Omega_1}\|S-G\|\le1000\},
\qquad
\mathcal C_\eta=\{S\in\mathcal K_{\rm dir}:J(S)\le(1+\eta)J^*\}.
$$

$P$ 用于求定位直径；$\Omega_1$ 用于表达目标场景；$\mathcal K$ 是保证接收的站点集合；$\mathcal C_\eta$ 是满足近最优质量的站点集合。可靠测向域还要求 $\operatorname{dist}(S,\Omega_1)>5$ 米。

即使 $P$ 在物理圆之外延伸，其直径仍按第一问计算。这是为了保持评价指标一致；若未来希望研究 $P\cap\Omega_1$ 的物理裁剪直径，应另立扩展模型并重新说明算法适用性。

## 4. 解析结论的条件

中心线近似中的 $(750,\pm661.4378)$ 米，只针对目标距离区间 $[0,1500]$ 与最小接收半径 $1000$ 米。它们是两个端点圆的交点和透镜最大侧向偏移点，不是完整角域模型的最优点。

标准完整 $\pm1^\circ$ 角域下，该解析点的最远目标距离约为 $1017.3366$ 米，未通过本文统一 $1000$ 米准则，最终候选须经连续可靠性检验和修正。这不排除利用首次成功条件后存在更宽松保证。受目标圆裁剪后的距离区间、边界和最优两侧区域均可能变化。

一阶误差带公式

$$
D_{\rm lin}=\frac{2\sqrt{w_1^2+w_2^2+2|\cos\varphi|w_1w_2}}{|\sin\varphi|},
\qquad w_i=d_i\tan\delta,
$$

在非平行、局部小角度条件下解释几何影响。它不是前向角楔交集的精确直径，也不构成“只要 $90^\circ$ 就最优”的一般结论。移动站点会同时改变交会角和站源距离。

## 5. 连续结论与数值近似

| 内容 | 连续数学层 | 本次数值层应如何解释 |
|---|---|---|
| 物理边界 | 有效线段与圆弧 | 精确结构加浮点参数；画图折线不改变模型定义 |
| 接收保证 | 对全部 $G\in\Omega_1$ 的距离上界 | 用连续边界距离极值及安全裕度检查，不能只检有限采样点 |
| 内层降维 | 全部可能第二示向度为一个扩张角区间 | 降维本身精确；区间上的数值峰值搜索仍是近似 |
| 最坏直径 | $J(S)=\sup D(P)$ | $\widehat J$ 为实际搜索到的值，可能低估未解析证实的连续峰值 |
| 最优方案 | $J^*=\inf_{S\in\mathcal K_{\rm dir}}J(S)$ | $\widehat J^*$ 由网格与局部细化获得，未声称全局最优证明 |
| 候选区域 | 连续次水平集 $\mathcal C_\eta$ | 保存规则格网近似；图中插值区域不额外提供连续性能证书 |
| 区域面积 | 连续集合面积 | 规则网格单元计数估计，须报告步长和加密变化 |

若只在有限个真实场景中求最大值，该值通常是连续最坏值的下界。若误差方向区间使用数值外包，则该外包只保护方向覆盖，仍不能自动保证有限峰值采样找到了最大直径。接收保证与质量最优的证据等级不同，应分别说明。

## 6. 必须显式处理的边界状态

| 情形 | 正确处理 |
|---|---|
| 首次物理可行域为空 | 报告首次输入与物理先验不相容，不返回伪造候选区 |
| 中心线无有效距离区间，但角域仍与目标圆相交 | 解析候选不适用，完整物理模型继续判断 |
| 两个端点圆分离或相切 | 分别报告线段近似无可靠位置或只有相切点，不能开方负数 |
| $\max\|S_2-G\|>1000$ | 标为未通过本文统一接收准则，不据此否定条件模型保证或断言实际必然失败 |
| $\min\|S_2-G\|\le5$ | 存在近距无示向度场景，不能作为保证两次测向的方案 |
| 精确角域交会无界 | 直径视为无穷，数值搜索给予最差质量；JSON 用状态与空值表达 |
| 理应相容的目标—误差场景返回空集 | 报告并检查输入、角度约定、离散或浮点问题，不记为零直径 |
| 角区间跨越零度 | 使用连续展开分支，不用简单角度最大减最小 |
| 目标可行域相切或退化为线段、点 | 根据物理模块支持范围显式返回状态或说明不适用，不伪造面积 |
| 搜索网格内没有可靠候选点 | 区分连续可靠域为空与网格遗漏；检查分辨率和连续几何 |

## 7. 复用与本轮结论边界

第二问对第三问提供数值候选点、质量指标、移动距离、可靠性余量及首次输入。第三问应在这些对象上继续安排路线，不能把图片当作唯一接口。

本轮只做第二问理论建模和构造数值实验，未提供官方模拟器正式成绩。未将定向干扰源策略、多个干扰源关联、实际障碍可达性或整条路线时间纳入第二问主模型；若后续任务引入这些约束，应在候选区域基础上继续筛选并重新核查可行性。
