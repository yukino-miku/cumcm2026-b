# 透镜顶点连线与目标圆交点策略核查

本记录检验用户提出的简化策略：未截断时选透镜两顶点，出现目标圆截断时，取两个顶点的连接线段与目标圆边界的交点作为第二站。以下均为构造算例，非官方模拟器测试。复核日期：2026-09-11。

## 1. 结论与适用范围

该规则可以作为待评价的几何候选生成方式，但不是普适的可靠选点方法：交点可能不存在，延长线的交点可能不在线段内，所选点也可能违反二次接收约束。即使满足检测条件，交点也不自动使最坏定位直径最小。

未截断情形中，(750,±661.438) 是中心线距离区间 [0,1500] 的透镜最大侧向偏移点，不是完整 ±1° 模型的数值最优点。现有标准数值解约为 (798.303,±602.257)。两者的角色不能混淆。

1800 米目标圆约束的是未知目标 G 的位置；第二站的统一可靠域是所有 G 对应的 1000 米圆之交，二者属于不同集合。题面也允许检测站在目标圆外，因此第二站没有必须落在目标圆边界上的要求。

## 2. 沿用未截断透镜：直线与圆没有交点

采用已经归档的截断案例：第一站 S1=(1200,0)，第一次测得方向为正东，目标圆为 x²+y²≤1800²。

如果保持原 0～1500 米中心线透镜，其两顶点全局坐标为

\[
A_\pm=(1200+750,\ \pm661.4378278)=(1950,\pm661.4378278).
\]

两点连线为 x=1950。代入目标圆边界：

\[
y^2=1800^2-1950^2=-562500<0.
\]

所以不仅连接线段没有交点，即使延长成无限直线也没有交点。首次目标扇区确实已被目标圆截断，但这不能推出透镜顶点连线会与目标圆相交。

## 3. 按截断后的区间重画透镜：延长线交点越出线段且不能保证接收

若先将中心线区间更新为 [0,600] 米，再画两个端点的 1000 米圆，则透镜两顶点为

\[
A_\pm=(1500,\pm\sqrt{1000^2-300^2})
       =(1500,\pm953.9392014).
\]

顶点连接线段为 x=1500、|y|≤953.9392014。无限直线与目标圆相交于

\[
Q_\pm=(1500,\pm\sqrt{1800^2-1500^2})
      =(1500,\pm994.9874371).
\]

两个交点都超出连接线段，因此按用户原先的线段规则仍然没有交点。若额外允许延长线，并选择 Q₊，可以构造明确的物理反例：

\[
G=(1206,0),\quad R=1000\text{ 米}.
\]

G 位于目标圆和首次扇区内，距第一站 6 米，超过 near 的 5 米阈值，首次测得 0° 完全合法。但

\[
\|Q_+-G\|=\sqrt{294^2+994.9874371^2}
\approx1037.514337\text{ 米}>R.
\]

所以机器狗在 Q₊ 无法接收这个合法目标。这里的失败不只是“未通过保守的统一 1000 米准则”：R=1000 与首次成功信息完全相容，确实存在合法检测失败场景。Q₋ 的镜像情形同理。

## 4. 直接调用现有模型的数值核查

调用 `robust_objective`，使用 513 个观测角节点、局部峰细化、第一问原函数复核。以下均使用完整精度坐标计算，表中数字仅供展示。

| 第二站 | 对整个 Ω 的最远距离（米） | 对整个 Ω 的最近距离（米） | 几何最坏直径（米） | 通过本文可靠测向准则 |
|---|---:|---:|---:|---|
| 目标圆交点 (1500,994.987437) | 1049.252792 | 989.600174 | 50.369830 | 否 |
| 已归档数值方案 (1664.6,413.6) | 622.027427 | 405.428619 | 32.028132 | 是 |

不可靠位置的几何直径只是假设获得第二次角度后的对照指标，不能当成能够实际获得观测的保证。本表使用与正式第二问一致的纯角域定位直径，没有加入额外物理裁剪。

## 5. 可以怎样保留这个想法

把边界交点作为启发式候选时，先检查是否存在且落在连接线段内，再检查对 Ω 的连续最远距离、最近距离，最后计算 J 并与其他可靠候选比较。接收条件和定位效果仍然需要验证，不能仅由“落在目标圆边界”得出。

若希望简化二维搜索，可以尝试固定中心线中点 m，只在直线 S2=S1+m e+t n 上做一维约束搜索，而不是指定目标圆交点。由于固定了轴向位置，这会限制解空间，也不保证达到当前二维搜索的最佳值；本轮未将此扩展实现或替换正式算法。

## 6. 最小复核代码

在项目根目录、已配置环境下运行以下 Python 片段即可复算主要数值：

```python
import sys
import numpy as np
sys.path.insert(0, "src")
from cumcm2026_b.q2_physical_geometry import build_physical_region
from cumcm2026_b.q2_active_localization import robust_objective

region = build_physical_region([1200, 0], 0)
point = np.array([1500.0, np.sqrt(1800.0**2 - 1500.0**2)])
target = np.array([1206.0, 0.0])
assert region.contains(target)
print("合法目标到交点距离：", np.linalg.norm(point - target))
for station in [point, [1664.6, 413.6]]:
    result = robust_objective(region, station, angle_count=513,
                              refine=True, verify_q1=True)
    print(result["station"], result["diameter_m"],
          result["max_distance_m"], result["min_distance_m"],
          result["reliable_bearing"])
```
