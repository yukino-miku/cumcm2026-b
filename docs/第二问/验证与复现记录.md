# 第二问验证与复现记录

全部计算均为**构造算例，非官方模拟器测试**。第二问沿用第一问定位区域直径，新增物理圆弧模块和鲁棒选点模块；第一问核心、原有配置、测试、图表及文稿由 SHA256 清单保护。

## 实际测试与运行入口

开始新增文件之前，第一问基线实际运行结果为 `41 passed in 1.10s`。第二问核心完成后全库实际结果为 `83 passed in 3.03s`，其中第一问 41 项、新物理几何 20 项、新鲁棒选点 22 项。

最终抽查发现截断案例楔尖附近的批量容差问题：旧 1e−9 筛选容差可接受轻微违约交点，使直径高出约 1.7e−5 米。将第二问批量容差收紧为 1e−10，保留第一问不变，并增加独立原函数回归用例。修正后于 **2026-09-11** 实际完整运行 `scripts/run-q2.ps1`，结果为 **`84 passed in 2.88s`**（41+20+23），重新计算和生成全部资产，退出码 0。

同一次完整入口的交付验收输出：**10 份严格 JSON、1843 个公开近优点连续距离核查、44 次更密角网格与第一问原函数抽查、10 组 PNG/SVG、76 个本地链接，全部通过**；计算与绘图来源哈希一致，第一问 29 个受保护文件保持不变。1843 是四案 2%/5%/10% 点集各自去重后的总数，不是 5% 点数或概率样本数。

在项目根目录执行完整验收：

```powershell
pwsh -NoProfile -File .\scripts\run-q2.ps1
```

入口依次运行全部测试、构造计算及全部图表生成、严格结果验收，任一阶段失败即停止。环境见[环境说明](../../environment/README.md)：Python 3.12.14、NumPy 2.3.5、SciPy 1.18.1、Matplotlib 3.11.1、pytest 9.1.1；第二问没有新增第三方依赖。

仅重新排版图表可运行 `scripts/run-q2.ps1 -PlotsOnly`，保留原计算来源记录；`-SkipTests` 仅供调试，不属于完整验收。非 Windows 环境可在配置相同依赖后依次执行：

```bash
python -X utf8 -m pytest -q
python -X utf8 scripts/build_q2_assets.py
python -X utf8 scripts/verify_q2_results.py
```

## 构造计算规模与参数

四个主构造覆盖标准中心、偏离圆心、目标圆明显截断、近圆边缘非对称。正式参数：O=(0,0)，目标圆半径 1800 米，首次接收上界 1500 米，二次统一保证下界 1000 米，角误差半宽 1°，near 半径 5 米，距离安全裕度 1e−5 米。

主搜索采用 25 米格网、65 个内层角节点；两侧多起点以 10/2/0.4 米细化并用 SLSQP 调整。潜在 10% 以内近优点使用 257 个角节点与峰值细化重新评价，最终最佳点调用第一问原函数核查。四案保存评价记录分别为 7141、7141、7141、6980 条，其中包含不可靠点及无界状态，不能把总记录数当有效候选点数。

每案独立目标验证点数依次为 651、646、651、646，覆盖角域边、圆弧、端点及内部层。标准案例另用 5、9、17、33 个等间距误差值，最粗误差组为 −1°、−0.5°、0°、0.5°、1°。完整主结果见[标准构造案例输入输出](../../results/tables/第二问/标准构造案例输入输出.json)与[鲁棒搜索输入输出](../../results/tables/第二问/鲁棒搜索输入输出.json)。

## 灵敏度和策略对比

误差半宽取 0.5°、1°、1.5°、2° 时，固定标准最优站的最坏直径约为 64.147、134.974、213.780、302.218 米，随误差增加。重新优化的结果及输入见[角度误差敏感性](../../results/tables/第二问/角度误差敏感性.json)。

还比较统一保证半径 950/1000/1050 米，以及通过第一站位置改变中心线距离上界至 600/900/1200/1500 米。前者除 1000 米外仅是参数扰动，不能冒充题目正式参数；后者保持目标圆和正式接收范围不变。数据见[物理范围敏感性](../../results/tables/第二问/物理范围敏感性.json)。

六策略比较包括沿线、原点侧移、中点侧移、原始中心线解析点、按完整模型回缩的解析点、数值优化点。标准回缩解析点直径约 139.228 米，优化后约 134.974 米；原始解析点未过本文 1000 米准则，不能与可行方案混合排名。沿线点可能进入 near 不确定区；独立调用第一问的同向交会核查确认为无界。详见[策略对比汇总](../../results/tables/第二问/策略对比汇总.md)。

## 文件来源与交付验收

[计算配置与来源](../../experiments/第二问/计算配置与来源.json)保存实际配置、计算源码与输入 SHA256、第一问受保护文件 SHA256，以及生成时的已有 Git 提交。该提交号可能早于成果提交，因此以源码哈希识别实际计算版本。[实验配置与环境](../../experiments/第二问/实验配置与环境.json)另存绘图版本和归档结果哈希；仅重画不得覆盖计算来源。

[结果验收脚本](../../scripts/verify_q2_results.py)核查全部第二问 JSON、候选点连续最远/最近距离与移动距离、阈值索引、近优点细化标志，并逐案分层抽查近优点，以 513 个角节点加峰值细化及第一问原函数再核验。它还检查图表 PNG/SVG 配对、SVG XML、中文交付文件和本地链接。

本轮生成 10 组中文图（10 PNG、10 SVG），均有来源标记。可直接取材的公式、表格与图引用见[论文备用稿](../../paper/sections/第二问_论文备用稿.md)，计算说明见[构造实验报告](../../experiments/第二问/构造实验报告.md)。本轮未调用官方模拟器，未执行第三问或第四问。
