## 2. 自动测试及独立依据

两份测试文件合计 **41 项**，已实际运行通过。

| 测试范围 | 核查依据 |
|---|---|
| 前向角域与角度约定 | 已知东西方向点、跨越 0°/360° 的等价输入，避免误取反向角域 |
| 凸多边形、线段、单点、空集和无界 | 可直接判断的解析几何对象及线性约束 |
| 直径与覆盖判定 | 已知矩形、等边三角形等几何结论 |
| 可实现正多边形 | 3、4、5、8 边形，各作 3 种旋转，共 12 组；先独立检查角域包含原顶点，再与解析顶点和直径比较 |
| 平移、旋转、缩放 | 欧氏距离不变性及尺度关系，避免坐标相关错误 |
| 近乎平行的约束 | 包含约 5729.6 万米远顶点的有界构造，检查算法没有用人为大矩形截断 |
| 非法输入及数值容差 | 非有限数值、不匹配数组、无效误差半宽和无效容差必须报告错误 |

正多边形的独立直径公式为：外接圆半径为 $R$ 时，偶数边形的直径为 $2R$，奇数边形为 $2R\cos(\pi/(2n))$。偶数边形可被同直径圆覆盖，奇数边形不能。测试由这些解析结论给出预期值，并非把被测实现重新抄一遍。

测试文件：[基本几何测试](../../tests/test_q1_geometry.py)、[解析正多边形测试](../../tests/test_q1_reference_polygons.py)。

## 6. 数值边界与适用范围

数学定理为精确结论，实现采用浮点线性规划及几何运算。默认在平移缩放后的坐标中使用 `1e-9` 长度容差，结果保留原坐标容差供复核。处于容差尺度的微小区域或接近圆边界的覆盖情形，应结合输出容差判断，必要时提高精度独立复核。

该实现优先保证可解释性：两两求约束边界交点并对所有约束筛选，几何求交部分最坏为 $O(n^3)$；顶点对直径为 $O(m^2)$，另有线性规划开销。它没有实现文献中的最优复杂度半平面交算法或旋转卡壳，不能在论文中把优化方法的复杂度写成当前实现的复杂度。
