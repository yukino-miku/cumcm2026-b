## 2. 第一问的核心答案

每个检测点的测得方向左右各偏转 $1^\circ$，形成一个前向角域。每个角域可写成两个半平面，全部角域的交集在非空、有界且具有内部时为凸多边形。

若其顶点为 $V_1,\ldots,V_m$，定位区域直径为

$$
D=\max_{1\leq i<j\leq m}\|V_i-V_j\|.
$$

任取实现直径的一对顶点 $A,B$，令 $M=(A+B)/2$。存在直径为 $D$ 的圆盘覆盖整个区域，当且仅当

$$
\max_k\|V_k-M\|\leq D/2.
$$

该条件并非总成立。三个满足题设误差范围的角域可以交成边长 20 米的等边三角形：$D=20$ 米，任何候选半径 10 米的覆盖圆都不能包住整个三角形。具体可实现构造与证明见推导稿第 7 节。

第一问没有指定必须计算的数值表，因此结论是一般算法与判定方法，构造实验用于核对算法。模型使用示向误差角域，不额外与半径 1800 米的先验圆或接收距离圆求交。

## 4. 一条命令复现

在项目根目录 `D:\mywork\code\cumcm2026-b` 执行：

```powershell
pwsh -NoProfile -File .\scripts\run-q1.ps1
```

入口先执行 41 项测试，再计算四组通用配置，最后重建全部图表、203 组图表实验数据及环境记录。输出保存在现有结果目录；复现脚本本身不提交 Git。环境安装见 [环境说明](../../environment/README.md)。

只计算自己的数据时，可复制 [q1_cases.json](../../configs/q1_cases.json) 为新文件并修改输入，再调用：

```powershell
.\.venv\Scripts\python.exe -X utf8 src/cumcm2026_b/q1_geometry.py --cases configs/q1_cases.json --output results/tables/第一问/通用算法输出.json
```

上面的命令使用仓库内四组示例。实际使用新输入时替换 `--cases` 与 `--output` 路径，保留原构造配置便于回归核对。

## 5. 输入输出与接口

程序保留稳定的英文字段名，中文含义如下。

| 输入字段 | 含义与约束 |
|---|---|
| `cases` | JSON 顶层的案例列表 |
| `id`、`name_zh` | 案例编号及中文名称 |
| `stations` | 检测点坐标列表 `[[x1,y1],[x2,y2],...]`，单位米 |
| `bearings_deg` | 与检测点逐一对应的示向度，从 $x$ 轴正向逆时针计，单位度 |
| `half_width_deg` | 误差半宽，题设取 `1`；接口也支持每站单独给定，均须严格介于 0 与 90 度之间 |

| 输出字段 | 中文含义 |
|---|---|
| `kind`、`kind_zh` | 区域类型及中文名：空集、无界、有界凸多边形、线段、单点 |
| `vertices` | 有界区域的边界顶点；多边形按逆时针排列 |
| `diameter`、`diameter_pair` | 区域直径及实现该直径的一对顶点 |
| `circle_center`、`cover_radius` | 直径端点中点及候选半径 $D/2$；此半径不表示最小覆盖圆半径 |
| `max_center_distance`、`coverage_excess` | 最远顶点到候选圆心的距离，以及超过 $D/2$ 的非负距离 |
| `covered` | 在记录的数值容差下，同直径圆是否覆盖 |
| `A`、`b` | 原坐标下的半平面约束 $AX\leq b$ |
| `normalization_origin`、`normalization_scale` | 数值求解采用的平移原点与长度尺度 |
| `tolerance`、`absolute_tolerance` | 归一化坐标容差与换回原坐标后的长度容差 |
| `feasible_point` | 线性规划返回的一个可行点；空集时不存在 |

空集与无界区域的有限直径及圆覆盖字段输出 `null`，须先读取区域类型。无界区域的数学直径为无穷，空集的直径在本实现中不定义；二者不能解释成直径零。单点直径为零，线段直径为端点距离。

在已经将 `src` 加入 Python 模块搜索路径的程序中，可调用 `solve_bearings(stations, bearings_deg, half_width_deg=1.0)`。已有线性约束时可调用 `solve_halfplanes(A, b)`。完整参数说明及错误提示见源码。

## 6. 复用时保留的条件

- 输入示向度须来自同一干扰源，本问没有实现多源测量关联。
- 误差仅有确定性范围，不能把构造扫描的覆盖比例当成覆盖概率。
- 新增圆域、障碍或非凸排除区后，应重新核对几何对象与直径算法的适用性。
- 第一问到此完成；后续问题的策略、模拟器实验和整篇论文排版另行开展。
