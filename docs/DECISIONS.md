## 第二问建模与实现决策

| 问题 | 选择与理由 | 验证与限制 |
|---|---|---|
| 首次不确定集合无界 | 用首次角域与 1500 米接收圆、1800 米目标圆相交 | O=(0,0)来自正式题面；独立圆弧物理模块，不改变第一问定位多边形 |
| 首次5米内区域 | 保守保留 | 扩大不确定集合，避免低估风险；该闭凸外包使后续几何与降维可解释 |
| 接收与示向度区别 | K保证接收；实际搜索再要求距Ω至少5米加正裕度 | 原文near状态没有示向度；为保持实际安全裕度，区分理论开放条件与数值内缩域 |
| 连续可靠性怎样检查 | 线段/圆弧端点及径向驻点计算最大、最小距离 | 不用稀疏采样最大距离充当保证；默认几何容差1e-8米、搜索裕度1e-5米 |
| 解析策略是否最终答案 | 透镜最大侧向交点作为初值和基线 | 标准解析点对完整扇区最远距离1017.336587米，超过1000米，须修正 |
| 内层鲁棒计算量 | 利用凸域的连续方向像，将G和误差精确降为一维观测角区间 | 降维为数学等价；一维极大化仍为数值近似，另做G乘误差采样对照 |
| 怎样继承第一问 | 直接接口调用原solve_bearings；大量评价用等价批量四边界交点计算加速 | 原第一问测试保持通过，批量算法与原函数逐类对照，最终最坏场景原函数核验 |
| 外层优化 | 规则格网、两侧多起点局部细化、SLSQP微调 | 不宣称严格连续全局最优；所有潜在近优点再以更密内层网格复核 |
| 候选区域怎样输出 | 数学C_eta、数值评价近优点集、规则格网面积估计分别保存 | 单元内部或插值轮廓不自动保证近优；移动距离独立保存供第三问使用 |
| 采样是否概率 | 全部确定性构造，无目标或误差分布假设 | 均值/分位数仅描述离散场景，不能解释成实际概率 |
| 结果可追溯性 | 分开记录计算源码哈希与绘图源码哈希，仅重画不能冒充重新计算 | 计算期间源码变化即报错；第一问受保护文件构建前后校验 |

### 2026-09-11 最终复核补充

- 首次接收成功还蕴含 R≥‖G−S1‖，故统一 1000 米域是保守充分域；历史表中解析点“须修正”限定于该域，不能推断其在更大条件可靠域内必然不可靠。最终文稿和图表统一限定结论范围。
- 分层抽查发现截断案例楔尖附近，批量顶点接受容差 1e−9 会接受轻微违约点，导致直径比第一问高约 1.7e−5 米。将第二问批量筛选默认容差收紧为 1e−10，并新增固定角度独立原函数回归用例。第一问代码及容差不改。修正后完整重算，并再次执行更密角网格和第一问抽查。
