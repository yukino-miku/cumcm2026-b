## 第一问建模与实现决策

| 问题 | 本次选择 | 依据及验证 |
|---|---|---|
| 怎样表示测向误差 | 每个前向 ±1° 角域转为两个半平面 | 与附录 2 一致；不设随机分布；方向及跨零测试通过 |
| 是否加入圆形先验及距离约束 | 第一问只采用题目多边形角域交集 | 加圆域会出现圆弧，加入排除区可能失去凸性，需另立扩展模型 |
| 怎样处理无界区域 | 先做可行性及坐标方向有界性线性规划检查 | 不用任意大矩形截断；无界测试及极远有界顶点测试通过 |
| 怎样计算直径 | 边界交点筛选形成顶点，枚举顶点对 | 正确性易于复核；与解析正多边形比较通过，明确实际复杂度 |
| 同直径圆怎样判定 | 检查任一直径点对中点到全部顶点的距离 | 必要充分性已证明；等边三角形及可覆盖情形均已验证 |
| 反例能否由测向形成 | 构造三站形成边长 20 米等边三角形 | 三站测向为 1°、121°、241°，距离及角域均可核对 |
| 数值误差如何处理 | 中心化、缩放和显式容差，保留归一化参数 | 平移旋转缩放和近乎平行测试通过；浮点边界限制另行说明 |
| 用什么验证数据 | 确定性构造与独立解析结果 | 无指定第一问数值表；不混称官方模拟器测试或覆盖概率 |
| 如何支持队友与论文 | 中文推导、导航、记录、图表和备用稿 | 后续每题沿用；图表保存 PNG 与 SVG，结果和源码同步入库 |
