## 当前测试命令

模拟器已准备好时，在PowerShell运行：

```powershell
Set-Location 'D:\mywork\code\cumcm2026-b'
.\.venv\Scripts\python.exe -X utf8 .\scripts\run_q3_scheme1.py --mode http --robot-id '你的队号'
```
