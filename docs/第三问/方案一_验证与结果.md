## 2. 成组本地对照

实际执行30个指定场景，每个分别关闭和开启顺路检测，共60次完整运行。目标数10/13/16，布局为均匀散布、圆周边缘、外围聚集和中心聚集；接收半径包含1000、1500及混合，误差包含固定坐标哈希误差、0、±1端点和按频道交替端点。种子为20260911至20260940；具体交叉组合保存在逐场摘要。

| 指标 | 关闭顺路检测 | 开启顺路检测 |
|---|---:|---:|
| 全部清除的场景 | 30/30 | 30/30 |
| 平均虚拟总时间（秒） | 4581.336 | 3862.598 |
| 各场景平均每目标时间的均值（秒） | 363.874 | 312.120 |
| 最小虚拟总时间（秒） | 2680.330 | 1266.249 |
| 最大虚拟总时间（秒） | 5780.869 | 5721.521 |
| 平均检测次数 | 99.600 | 120.933 |
| 30场清除失败总次数 | 30 | 38 |
| 本地平均程序时间（秒） | 1.015 | 0.874 |
| 本地最大程序时间（秒） | 1.625 | 1.407 |

开启顺路检测在19场更快、11场更慢，平均总时间降低约15.688%。它增加了一些检测和清除尝试，但在这组场景中减少了后续绕行；收益在聚集布局较明显。图1刻意使用编号0的固定场景，该场开启顺路检测更慢，没有只挑有利案例展示。

失败清除属于有限光学覆盖过程的合法尝试，已按每次3秒计入总时间，不是遗漏目标。所有带安全覆盖证书的清除均成功。评估器在全部60次记录中进行了**2137次正观测外包真值包含检查**，没有发现真实目标被错误排除；不存在频道与真实存在频道也无交集。

这是指定构造集的描述性结果，不代表未知官方分布上的全清概率或期望成绩。真实HTTP网络和官方程序负载未包含在本地运行时间内，不能据此承诺官方也只需1秒。

## 4. 复现

完整复现：

```powershell
pwsh -NoProfile -File scripts/run-q3.ps1
```

仅重画已有记录：

```powershell
pwsh -NoProfile -File scripts/run-q3.ps1 -PlotsOnly
```

只重画时检查原始归档、计算源码和配置的哈希；计算层变化必须完整重算。程序运行时间可能随负载变化；有限规划预算也可能在更慢设备上减少候选评估，实际评估数量和耗时逐次进入记录。
