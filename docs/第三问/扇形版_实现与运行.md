# 方案一扇形版：实现与运行

日期：2026-09-11。本版已实现七固定站、严格扇形清空、智能站复用和按需补漏。原方案一、方案二的源码、配置、运行入口和历史结果保留；本版使用独立入口进行测试。

## 1. 测试命令

先进入项目根目录，在PowerShell执行本地构造：

```powershell
Set-Location 'D:\mywork\code\cumcm2026-b'
.\.venv\Scripts\python.exe -X utf8 .\scripts\run_q3_scheme1_sector.py
```

连接已经启动并准备好的模拟器：

```powershell
Set-Location 'D:\mywork\code\cumcm2026-b'
.\.venv\Scripts\python.exe -X utf8 .\scripts\run_q3_scheme1_sector.py --mode http --robot-id '你的队号'
```

该命令实际调用HTTP接口，应按模拟器当前界面确认是演练还是正式场景。开发验证没有连接官方模拟器或消耗正式机会。原方案一的`run_q3_scheme1.py`继续运行此前路线版，用于对照；方案二入口不变。

每次结果默认保存至独立的`local-only/第三问/sector-模式-随机标识/`，控制台会输出具体目录。结果包括完整动作、逐扇形证据、源码SHA256、Git提交及运行时工作区是否有改动，方便随后追踪版本。含队号的HTTP请求日志继续留在Git忽略目录。

可选构造参数例子：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\scripts\run_q3_scheme1_sector.py --seed 20264911 --count 13 --layout boundary --radius min --error plus
```

`--no-reuse`关闭机会复用扫描，保留严格覆盖验收、按需补漏及邻近A类清除。默认配置见[扇形版JSON](../../configs/q3_scheme1_sector.json)。

## 2. 实际调度流程

1. 中心扫描后保留已有路线版的有界初始服务，再向东方固定站推进。初始段400米绕行与24动作预算只约束这段预处理，不用于否决后续扇形任务。
2. 外圈每个固定站检测完成后，处理其至下一站对应的60°闭扇形，半径始终为1800米；最后处理300°—360°扇形，不强制回到东方站。
3. 对所有已发现频道，按完整可能区域与当前扇形的相交关系确定责任。区域无交集，或交集被该频道既有无信号圆覆盖，才能在本扇形排除它。
4. 本扇形目标先按插入和局部反转规划顺序，全部任务排在下一固定站之前。A类在完整区域19.5米安全位置清除；B类比较补测点、后续完成和下一节点的共同服务费用，再执行一个实际动作并重规划。
5. 智能测向站和清除位置可以扫描其他频道。未知频道默认要求覆盖至少一半当前剩余盲区的质心面积估计，或保守证明能够覆盖全部剩余三角形；该筛选仅影响是否顺路扫描，不用于清空证明。
6. 已发现B类允许在共用站机会检测，即使不能保证收到信号，也将真实的无信号结果作为排除信息；主目标的计划测向仍要求完整区域最远距离不超过999.5米且最近距离超过5.5米。两类检测在安全性要求和日志用途上区分。
7. 已定位的邻近目标允许提前清除，包括未来扇形的目标；默认相对接到下一站增加路程不超过80米且本次移动不超过200米，避免中心附近目标被分多次远距离返回处理。每个清除动作仍验证完整区域证书。
8. 处理已知责任目标后，逐频道核验本扇形无信号覆盖。仍有缺口才在当前位置、残余三角形中心、后续线段或角平分线备选中选择能完成覆盖的点，不预设六个额外站。
9. 全部20个频道均取得本扇形排除/清除证据后，记录“扇形清空证书”再推进。若全局达到16个目标上界，可据题目上界提前完成，不强制走剩余站。

严格全清规则可能增加成本，特别是目标集中于中心但仍须排除外围未知频道的场景。减少尾段遗留不等于总时间一定减少，具体以同场景完整对照为准。

## 3. 覆盖证书及边界处理

[扇形几何模块](../../src/cumcm2026_b/q3_sector_geometry.py)用包含1800米真实圆的外切多边形与两条径向半平面求交，得到保守扇形。相邻扇形均包含边界，允许重复核查但不重复清除。

将保守区域三角剖分。只有某个三角形的所有顶点都位于同一个999.5米无信号圆内，才判定整个三角形被覆盖；不同顶点分别被不同圆覆盖不足以通过。无法判定的三角形按最长边细分，默认25米尺度和4096检查节点上限。超出预算只返回“未取得证书”，绝不当作已覆盖。

每个频道只使用它真实取得的无信号站坐标。扇形覆盖是逐频道证据，位置经过、其他频道检测、未来尚未执行的站点均不计入。六个闭扇形均有该频道排除证据时，能够合并为全域不存在证书。

目标清除始终检查完整观测区域，不将目标区域擅自裁到当前扇形再清除。若有限次方向补测仍无法定位，使用已有完整区域有限方格覆盖方法；失败清除费用正常记录。动作或现实时间不足时如实停止，禁止把未完成扇形标为清空。

## 4. 候选与参数的性质

[扇形策略模块](../../src/cumcm2026_b/q3_sector_strategy.py)保留第二问构造候选，并加入当前至后续节点的线段及偏移点。默认每次最多24个候选、9个可能反馈角节点、0.8秒规划预算、每源8次主测向，超过预算回退有限覆盖。

反馈分支比较完整后续清除/覆盖及接续终点的费用。未知频道覆盖比例以一次检测及切换的6秒费用折算为候选排序启发式，不宣称真实节省或连续最优性。候选预测和实际安全证书分离。

初始阶段使用旧路线模块；进入扇形之后采用本版联合选点和清空约束。新配置中的`route_action_limit`与`localization_detour_limit_m`仅用于初始段，不能理解为扇形内部仍有400米的硬拒绝。
