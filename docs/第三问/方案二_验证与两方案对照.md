## 2. 成组实验设计

种子20260911至20260940，共30个指定场景。目标数为10、13、16；目标布局为均匀散布、圆周边缘、外围聚集、中心聚集；接收半径为1000、1500或混合；角误差为按固定位置哈希、0、+1°、−1°或按频道交替端点。每个场景独立重置环境，分别运行：

1. 方案一默认版本，开启顺路检测。
2. 方案二14站主布局，开启扫描站原地证书清除。
3. 相同14站布局，关闭可选原地证书清除，near仍立即处理。
4. 方案二14站10米余量布局。
5. 方案二15站小余量布局。

共150次运行，其中方案二120次。输入与方案一上轮场景定义一致；本轮重新运行方案一作为同时期对照，没有修改方案一策略或旧归档。同一场景的五设置具有完全相同的目标、半径及误差生成规则。

相对方案一，14站主布局平均慢572.783秒，即14.829%；30场有8场更快、22场更慢。15站小余量布局平均比14站主布局少23.331秒，但仍比方案一慢14.225%，不能据此宣称15站在未知分布中最佳。

主布局与“延后清除”对照的虚拟结果完全相同。检查动作日志后确认：这30场中扫描阶段合计清除7个目标，全由near触发，没有触发可选的非near原地证书清除。不能将相同结果写成该功能普遍无效。新增独立非near用例验证开关确实改变清除阶段。

## 4. 双覆盖之后还剩什么

14站主布局30场共390个目标，扫描阶段清除7个，剩余383个均具备至少两处方向观测。其中295个的外包已经能用19.5米圆覆盖；88个尚不能通过该充分判据，需要后续更新信息或光学搜索。不能把88个全部称为“必须专门追加测向”，因为处理其他目标时的顺路检测也可能使其精度提高。

平均固定扫描阶段实际费用3147.124秒，后续精定位与清除1288.257秒，合计4435.381秒。实际扫描费用比3205.624秒全频道基准低，是因为省略了已经清除或证明不存在的频道；已发生的原地清除费用包含在实际扫描时间中。

方案二平均路程较短、专门追加测向较少，固定检测和切换数量则明显更多。这些费用解释了当前构造集上的平均总时间差。不同布局下的平均值也全部公开：

这是有限指定场景的描述性比较，不是成功概率、期望性能或全局最优性的证明。现阶段两套方法均保留；当前数据支持方案一作为较快的本地基线，方案二提供固定双覆盖扫描的完整对照。
