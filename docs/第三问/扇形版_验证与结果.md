# 扇形版验证与结果

日期：2026-09-11。固定实现为方案一七固定站、严格扇形清空、智能站复用及按需补漏。以下为本地构造数据，不是官方演练或正式成绩。

## 1. 结果及使用判断

开发集与独立验证集各30个场景，每场分别运行此前路线版与扇形版，共120次完整运行，均通过全清及费用核验。

独立验证集的此前路线版、扇形版平均总虚拟时间分别为3660.467、4061.460秒，扇形版相对变化+10.95%；5场更快、25场更慢。该结果没有支持“严格扇形版总体更省时间”的结论，适合作为有清空约束的可测试版本保留，不以其替换旧入口的默认行为。

扇形版实现了要求的逐扇形清空验收，独立验证集中“前序扇形目标延后清除数”均值为0.000，此前路线版为5.333。这说明它落实了任务处理时机约束，不代表每段实际移动都不反向，也不等于路线全局最短。

两版本验证集清除失败次数分别为6、4，相关费用均计入。有限覆盖中的尝试失败与带完整区域证书的清除失败不是同一概念，后者会停止策略核查。

## 3. 场景与信息隔离

开发集种子20260911起，其中前12个场景曾用于检查复用扫描及初始阶段行为；独立验证集种子20264911起，在参数固定后运行。目标数轮换10、13、16，布局轮换均匀、边界、外围聚集、中心聚集，接收半径轮换最低、最高、混合，误差轮换哈希、零、正端点、负端点、交替端点。

同一场景两版本使用完全相同目标、接收半径及误差生成函数。由于行动位置不同，收到的反馈可不同；不能把旧反馈固定后机械重放为新路线。策略只经协议读取响应，目标真值由结束后的评估器读取。

这是一组指定构造场景，不代表官方案例分布。未使用独立验证集结果再次调参，也不声称对任意目标布局、噪声和现实预算都必然全清。

## 4. 验收依据

已通过200项全库测试；最终小幅调整后又通过26项扇形回归。归档重放核查包括：每条检测/清除的位置与真实反馈、完整费用、外包包含真值、逐频道真实无信号站、每份扇形证书的三角细分覆盖、每次前往下一固定站之前的证书顺序，以及扇形中真实目标已清除。

本批验收计数：外包真值核查次数5386、动作数22448、停止检测证书数0、有证书跳过次数0、扇形证据行数7140、重新细分核查单元数85336。

“前序扇形目标延后清除数”根据目标真值的极角所属扇形及清除时已经开始的固定站序计算，只作离线几何诊断；真值没有传入调度器。精确位于圆心的目标不纳入该极角指标，完整清除验收仍包含它。
